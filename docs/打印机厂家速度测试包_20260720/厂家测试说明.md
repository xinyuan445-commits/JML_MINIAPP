# 标签打印速度对比测试

本测试包用于对比微信小程序修改前、修改后的蓝牙打印数据发送速度。

## 测试文件

- `01_修改前_位图CPCL_100字节分包.bin`
  - 按修改前小程序的发送结构复原。
  - 使用 CPCL `CG` 位图命令，文字、二维码和线框均变成黑白位图数据。
- `02_修改后_原生CPCL_GBK_100字节分包.bin`
  - 由当前小程序 `LabelPrint.js` 的实际打印数据生成。
  - 文字采用 GBK 编码，线框和二维码由打印机原生 CPCL 指令生成。
- 同名 `.hex.txt`
  - 二进制文件的十六进制表示，便于核对具体发送内容。
- 同名 `.base64.txt`
  - 二进制文件的 Base64 表示，便于通过文本方式传输。

## 蓝牙发送规则

1. 连接打印机支持 `write` 的 BLE 特征值。
2. 按文件原始二进制顺序发送。
3. 每包固定 `100` 字节，最后一包发送剩余字节。
4. 每次 `writeBLECharacteristicValue` 成功后立即发送下一包。
5. 包与包之间不主动增加延时。
6. 只打印一张。

## 数据量对比

| 方案 | 二进制大小 | 100字节分包数量 |
| --- | ---: | ---: |
| 修改前：位图 CPCL | 71,720 字节 | 718 包 |
| 修改后：原生 CPCL + GBK | 1,512 字节 | 16 包 |

修改后的发送数据约为修改前的 `1/47`。

## 测试建议

请分别记录两个 `.bin` 文件从发送第一包开始，到打印机开始出纸的时间，以及标签完全打印结束的时间。

测试时应使用相同手机、相同打印机、相同蓝牙连接和相同打印浓度。
