# 无工单任务入口性能优化与部署

日期：2026-11-13。用户授权优化、保持权限不变，测试通过后部署后端；第5阶段不做。

## 原因和改动

context原实现遍历全部有效员工，为每人单独读取账号、豁免及工站资格；同一人员出现在多个工站时，scope也重复查询账号。现场菜单和无工单列表均会请求context，放大等待。

共用包0.2.1将scope人员读取改为带参数的批量查询；核对候选从有效工站线长及豁免ID集合批量读取有效人员，任务参与排除也批量读取相关指派、时段、工作记录。保留现有事务内FOR SHARE及每次请求实时读取，没有跨请求权限缓存，没有取消操作时的资格／范围校验，没有改候选规则、API返回结构或小程序代码。
