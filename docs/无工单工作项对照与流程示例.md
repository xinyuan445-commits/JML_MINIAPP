# 无工单工作项对照与流程示例

依据 2026-11-13 对话中的工作安排原表，保留第 1～38 行的顺序。小程序已接入6个模块、36个可选工作项。流程中的日期、人员、工位和验收值均为演示数据。

## 选工作项后填什么

1. 先选工作模块，页面列出该模块的工作项。点选一项，就以原工作项名称建立一条分工。
2. 分工卡直接用下面的字段标题。通用字段为「本次要解决什么或达到什么」「验收要求」「执行人员」，界面按工作项换成具体名称，例如「清扫目标」「账实核对要求」。原表的范围提示用来确定字段和可选项。已有的内容和验收要求随工作项带入，缺少的本次信息由发起人补齐。
3. 工作内容由工作项名称和已填对象、范围组成。单人执行沿用整条分工，多人执行明确各自范围。计划日期可从总任务沿用，也可按分工调整。发布确认列出工作项、对象、人员、负责范围和验收要求；负责人参与执行时加上本人执行核对人。
4. 完成时由执行人记录实际结果。每条工作项的验收要求供核对使用。单条分工的总体标准可以沿用该项验收要求，多条分工建议汇总各项验收要求供发起人确认，保留原有总体完成标准。

表中的顿号连接同一条分工内可按需要填写的项目。原表要求把本次具体对象和范围、问题／原因／目标、验收要求说清楚。能从工作项或已选资料带入的值，用户可以直接确认。

## 三条工作项怎么走

### 工位清扫

1. **选项与填写。** 选「5S工作安排 → 工位清扫」。填写清扫工位「三号库打包工位」，清扫部位勾选「地面」「台面」「设备表面」。清扫目标「清除交接班后的纸屑和胶带残留」，验收要求「地面无杂物，台面和设备外表无胶带残留」。计划日期选 2026-11-13。
2. **指派与发布。** 指派张三。发布确认显示「工位清扫 · 三号库打包工位」「张三 · 地面、台面、设备表面」和验收要求。
3. **员工执行。** 张三打开即看到「工位清扫 · 三号库打包工位」、本人清扫部位和验收要求，依次接收、开工。完成后提交「地面纸屑及台面、设备表面的胶带残留已清理」，可附照片。
4. **核对。** 负责人对照原验收要求检查，核对通过后确认分工完成。

### 半成品盘点

1. **选项与填写。** 选「盘点工作安排 → 半成品盘点」。填写工序「打磨后暂存」、批次「B1113」、核对范围「T01～T08 托盘」。盘点目标「核实交接班账实差异」，验收要求「逐托盘登记实盘数量；有差异的标明托盘号、账面数和实盘数」。计划日期选 2026-11-13。
2. **指派与发布。** 指派李四负责 T01～T04，王五负责 T05～T08。确认时显示每个人的托盘范围和同一条验收要求。
3. **员工执行。** 李四看到 T01～T04，王五看到 T05～T08。各自接收、开工和提交。示例中李四提交「4 托盘已核对，账实一致」，王五提交「4 托盘已核对，T07 账面 20 件，实盘 19 件」。盘点记录可随附件提交。
4. **核对。** 负责人逐人看托盘范围和提交结果。差异已有登记，按这次约定的验收要求判断是否通过。两人核对通过后确认整条分工完成。

### SOP作业规范培训

1. **选项与填写。** 选「培训工作安排 → SOP作业规范培训」。填写「打包 SOP-PK-03」「打包岗位」。培训目标「统一换批时的标签核对方法」，验收要求「参训人员完成一次换批标签核对演示，登记结果」。在「参训人员」填「赵六 · 打包」「钱七 · 打包」。计划日期选 2026-11-13。
2. **指派与发布。** 指派陈八组织培训、示范并登记结果。发布确认把陈八列为执行人，把赵六、钱七列为参训人员。参训名单用来核对培训覆盖情况。
3. **员工执行。** 陈八看到 SOP、培训岗位、参训名单和验收要求。培训后提交「两人均完成演示，结果已登记」，可附签到或结果记录。
4. **核对。** 负责人对照参训名单与登记结果核对。若陈八就是任务负责人，发布时按现有规则另选合格核对人处理陈八本人的提交和相关分工确认。

发布前如果有缺项，建议提示具体工作项和字段，例如「半成品盘点 · 王五的盘点范围待填写」，点提示回到该条分工。工作项名称、对象、范围及验收要求随发布内容保存，核对时按执行人收到的要求查看。
