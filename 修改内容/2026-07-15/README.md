# 2026-07-15 工序报工修改记录

## 今日完成内容

### 工序流转标签打印

- 工序完工后增加“是否立即打印标签”的提醒。
- 完工记录中增加“打印标签”按钮，并显示历史打印次数。
- 每次固定打印 1 张，不允许一次选择多张。
- 增加蓝牙打印机搜索、连接、打印功能。
- 标签采用 100 × 180 mm，展示完整路线、当前工序、下一步、工单、行号、产品、A、A1、A2、C 数量和完工时间。

### 标签格式与打印效果

- 根据实物打印效果多次调整边距、分隔线、数量表格和二维码位置。
- 中文内容改为小程序生成后打印，解决打印机字体乱码问题。
- 优化蓝牙分包方式，减少 iPhone 发送打印时的等待时间和超时概率。
- 二维码改为由小程序直接生成，避免打印机错误解析 JSON 中的双引号。

### 二维码扫码追溯

二维码内容统一为：

```json
{"mocode":"工单号","sortseq":行号,"execid":完工记录ID}
```

- `mocode`：工单号。
- `sortseq`：工单行号。
- `execid`：本次工序完工记录ID。
- 扫码后可直接进入这一次工序的完工记录，而不是只进入普通工单详情。

### 第一工序领料检查

- 第一工序开工前，检查子件清单中的应领和已领数量。
- 检查料号以 `1`、`2`、`31` 开头的材料。
- 只要有一项“已领数量小于应领数量”，就不允许开工。
- 页面会显示未领齐的料号、应领数量和已领数量。
- 后端会实时读取 ERP 再检查一次，防止绕过小程序页面直接开工。
- 后续工序不做这项领料检查。
