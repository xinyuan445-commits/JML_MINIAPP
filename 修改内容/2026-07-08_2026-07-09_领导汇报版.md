# 生产报工功能优化汇报

汇报日期：2026年7月9日  
汇报范围：2026年7月8日 - 2026年7月9日修改内容

## 一、整体说明

这两天主要围绕生产报工流程做了优化，重点解决现场操作、人员记录、接收流转、返工追溯、照片留底等问题。

本次调整后，报工流程更加完整，现场人员操作更清晰，后续管理追溯也更方便。

---

## 二、人员选择优化

### 修改内容

1. 开工、接收、返工等环节都增加了人员选择。
2. 人员来源使用钉钉通讯录，包含姓名、手机号、部门信息。
3. 部门选择改成一级一级选择，避免所有人员堆在一起不好找。
4. 人员选择范围先保留金米龙、科米龙、金米龙江苏相关部门。
5. 增加临时工选择，可以根据现场实际人数选择多个临时工。
6. 不允许只选择临时工，必须至少选择一名正式员工。

### 作用

- 方便现场按实际参与人员报工。
- 历史记录中保留当时选择的人员，后续人员离职或部门调整，也不会影响旧记录。
- 临时工人数不固定时，也可以灵活记录。

## 三、完工记录优化

### 修改内容

1. 完工记录详情增加开始时间、结束时间、用时显示。
2. 用时自动换算，例如不足1分钟、几分钟、几小时、几天等。
3. 已完成的工序可以查看完整明细。
4. 有下一步工序时，可以从明细页进入下一步。
5. 按钮布局进行了优化，“进入下一步”作为主要按钮显示。

### 作用

- 完工记录更清楚，方便查看每道工序用了多久。
- 已完成工序不只是显示状态，也能看到具体内容。
- 后续工序流转更方便。

## 四、接收功能优化

### 修改内容

1. 将原来的“下线”调整为“接收”，更贴近现场操作。
2. 接收数量由用户自己填写。
3. 接收时会提示当前剩余可接收数量。
4. 接收时需要选择接收人员。
5. 接收时必须拍照上传，用于领用材料留底。
6. 接收记录支持多条历史记录展示。
7. 接收完工时需要填写A级数量和C级数量。
8. 接收完工后，会更新当前工序的总完成数量和结束时间。

### 作用

- 可以记录上一步工序交给当前工序的实际接收情况。
- 有照片留底，方便后续出现问题时追溯。
- 接收后再完工，流程更符合现场实际。

## 五、返工功能优化

### 修改内容

1. 完工明细中增加返工功能。
2. 返工对象为C级品。
3. 返工开工时需要填写返工数量和返工原因。
4. 返工开工时需要选择返工人员。
5. 返工开工必须拍照上传。
6. 返工完工时需要填写返工后的A级数量和C级数量。
7. 返工完工必须拍照上传。
8. 返工记录在详情页中单独展示。

### 作用

- C级品返工过程可以单独记录。
- 能看清楚返工投入多少，返工后变成多少A级、多少C级。
- 返工前后都有照片，便于质量追溯。

## 六、拍照留底优化

### 修改内容

1. 完工时必须上传完工产品照片。
2. 接收时必须上传领用材料照片。
3. 接收完工时必须上传接收完工照片。
4. 返工开工时必须上传返工开工照片。
5. 返工完工时必须上传返工完工照片。
6. 详情页中的照片支持折叠展示。
7. 所有照片支持点击查看大图。

### 作用

- 关键生产节点都有照片留底。
- 后续出现数量、质量、交接争议时，可以直接查看照片。
- 图片折叠展示后，页面不会显得太乱。

## 七、页面显示优化

### 修改内容

1. 接收记录、返工记录改成卡片形式展示。
2. 多条记录支持折叠，避免页面内容堆在一起。
3. 子件清单取消固定小区域滚动，改为跟随整个页面上下滑动。
4. 接收数量输入框变得更明显，减少误点提示文字的问题。
5. 按钮布局调整，主按钮和辅助按钮层次更清楚。

### 作用

- 页面更容易看。
- 现场人员操作时更不容易点错。
- 多条记录也不会把页面撑得很乱。

## 八、工艺路线相关优化

### 修改内容

1. 报工使用的工艺路线和报价使用的路线做区分，避免互相影响。
2. 对部分重复工序做了合并处理，例如双面工艺中重复出现的修补、肤感烤漆等。
3. 补充了部分HPL路线中的粘贴垫板工序。
4. 工艺路线后续支持启用、禁用，减少直接删除带来的历史数据风险。
5. 管理后台中限制路线删除规则：只有管理员可以删除，且只能删除没有使用过的路线。

### 作用

- 报工路线更符合实际生产操作。
- 历史报工记录不容易被后续路线调整影响。
- 管理上更安全。

## 九、钉钉人员同步

### 修改内容

1. 增加钉钉用户和部门同步。
2. 同步内容包括用户、手机号、部门、部门层级。
3. 计划每天凌晨自动同步一次。
4. 后续可增加手动同步入口。

### 作用

- 人员新增、离职、部门调整后，不需要每次手动改系统记录。
- 报工时可以直接选择最新人员。
- 历史报工仍然保留当时人员信息。

## 十、本次修改效果总结

本次修改后，生产报工流程从“只记录完工结果”，进一步完善为：

1. 谁开工、谁接收、谁返工，都能记录。
2. 接收、完工、返工等关键环节都有照片留底。
3. 完工数量、A级数量、C级数量更加清楚。
4. 已完成记录可以查看明细，也可以继续进入下一步。
5. 返工过程可以单独追踪。
6. 页面操作更顺手，记录展示更清晰。

整体上，系统对现场生产过程的记录更完整，也更方便后续管理、查账和质量追溯。
