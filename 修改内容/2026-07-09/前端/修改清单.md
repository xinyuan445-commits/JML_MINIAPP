# 2026-07-09 前端修改清单

涉及文件：

- `JML_WX_miniapp/Mo/ProcessMgmt/Detailed.js`
- `JML_WX_miniapp/Mo/ProcessMgmt/Detailed.wxml`
- `JML_WX_miniapp/Mo/ProcessMgmt/Detailed.wxss`

## 一、完工产品照片

1. 完工弹窗增加“完工产品照片”拍照上传入口。
2. 完工提交时必须带 `complete_photo_url`。
3. 未拍照时前端提示：请先拍完工产品照片。
4. 完工记录详情的“照片留档”中展示完工产品照片。

## 二、接收 / 领用照片

1. 接收弹窗增加领用照片上传入口。
2. 接收数量输入区域改成更醒目的卡片式输入。
3. 接收数量默认由用户填写，不再自动填入。
4. 接收作业历史中展示：
   - 领用照片
   - 接收完工照片
5. 接收作业历史和照片做折叠展示，减少页面堆叠。

## 三、接收完工照片

1. 接收完工弹窗增加拍照上传入口。
2. 接收完工提交时必须带 `complete_photo_url`。
3. 接收完工照片在完工记录详情中展示。

## 四、返工开工 / 返工完工照片

1. 返工开工弹窗增加“返工开工照片”拍照上传入口。
2. 返工开工提交时必须上传照片。
3. 返工完工弹窗增加“返工完工照片”拍照上传入口。
4. 返工完工提交时必须上传照片。
5. 返工作业历史中展示：
   - 开工照片
   - 完工照片

## 五、图片预览

1. 完工记录详情中的图片支持点击查看大图。
2. 支持预览的图片包括：
   - 主材照片
   - 完工产品照片
   - 接收/领用照片
   - 接收完工照片
   - 返工开工照片
   - 返工完工照片
3. 弹窗中刚拍完的图片也支持点击预览。
4. 弹窗图片使用 `catchtap` 处理，避免点击预览时误触发重新拍照。

## 六、详情页布局

1. 子件清单取消局部固定滚动区域，改为跟随整页滚动。
2. 照片留档做成折叠区。
3. 接收作业、返工作业图片改为轻量缩略图卡片。
4. 页面底部增加安全区域留白，减少被底部操作条遮挡。
