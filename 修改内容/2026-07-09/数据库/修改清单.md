## 一、完工产品照片字段

表：`mo_execution_yx`

新增字段：

- `complete_photo_url VARCHAR(1000) DEFAULT NULL COMMENT '完工产品照片'`

用途：

- 保存普通工序完工时上传的成品照片。

## 二、交接接收 / 领用照片字段

表：`mo_handover_yx`

新增字段：

- `receive_photo_url VARCHAR(1000) DEFAULT NULL COMMENT '领用材料照片'`

用途：

- 保存后续工序接收/领用材料时上传的照片。

## 三、接收作业照片字段

表：`mo_receive_work_yx`

字段调整：

- `photo_url` 的含义调整为“领用材料照片”。

新增字段：

- `complete_photo_url VARCHAR(1000) DEFAULT NULL COMMENT '接收完工照片'`

用途：

- `photo_url` 保存接收开工/领用时的照片。
- `complete_photo_url` 保存接收完工时的照片。

## 四、返工作业照片字段

表：`mo_rework_yx`

新增字段：

- `photo_url VARCHAR(1000) DEFAULT NULL COMMENT '返工开工照片'`
- `complete_photo_url VARCHAR(1000) DEFAULT NULL COMMENT '返工完工照片'`

用途：

- 返工开工、返工完工分别留照片，方便后续追溯。

## 五、执行情况

以上字段已在 db2 执行补丁。
