# 报价计算公式

## 一、成本归集

- 7 大成本类别：A 直接人工、B BOM材料、C 能耗、D 一次性耗材、E 维修、F 管理、G 设备折旧
- **F 管理成本按部门归集，暂不参与本报价计算**
- 计价单位：**每张板**（单位价，不乘数量）
- 金额一律保留两位小数，四舍五入

## 二、计算链路

1. 产品类别 → 默认且启用的工艺路线（`bj_route_yx`：`is_default=1 且 is_enabled=1`）
2. 路线工序（`bj_route_step_yx`，有序，带系数 coefficient）
3. 每道工序按"工序-成本类别对照"（`bj_process_cost_map_yx`）确定适用的成本类别，
   从对应成本表按 `process_code` 取单位成本 × 系数：
   - A→`bj_labor_cost_yx` B→`bj_material_cost_yx` C→`bj_energy_cost_yx`
   - D→`bj_consumable_cost_yx` E→`bj_repair_cost_yx` G→`bj_depreciation_cost_yx`
4. **占位工序（is_pending=1）不计入**，仅前端标记
5. 按成本类别汇总 A~G
6. 加公共成本（`bj_common_cost_yx`，按 cost_type **整单加一次**）

## 三、最终价格

界面填的合格率/毛利率/税率是**百分数**，计算时 ÷100 转比率。
**毛利率为成本加成**。**某个率为空，则跳过该步（等于不变）**。

```
① 直接成本合计   = ΣA+ΣB+ΣC+ΣD+ΣE+ΣG + 公共成本        ← 后端算
② 含格率成本     = 合格率有值 ? 直接成本 ÷ 合格率 : 直接成本
③ 不含税售价     = 毛利率有值 ? 含格率成本 ×(1 + 毛利率) : 含格率成本
④ 含税报价参考价 = 税率有值   ? 不含税售价 ×(1 + 税率)   : 不含税售价
```

## 四、示例（木质三胺烤漆板）

直接成本合计 61.45，合格率 91.80%，毛利率/税率暂空：

```
含格率成本   = 61.45 ÷ 0.9180 = 66.94
不含税售价   = 66.94            （毛利率空，跳过）
含税报价参考价 = 66.94            （税率空，跳过）
```

> 默认值：未单独设置一次合格率的产品类别，按 96% 计。毛利率、税率待补。
