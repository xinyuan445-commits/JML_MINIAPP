## 二、成本 / 报价公式（已确定）
```
成本未税     = 人工 + 能耗 + 辅材÷1.13 + Σ材料未税
成本含税     = 成本未税 × 1.13
含合格率成本 = 成本未税 ÷ 一次合格率
直营报价未税   = 含合格率成本 ×(1 + 直营毛利率)
经销商报价未税 = 含合格率成本 ×(1 + 经销商毛利率)
参考单价·含税  = 报价未税 ×(1 + 报价税率)
```
- **成本税固定 13%**（只作用于 辅材÷1.13、材料折未税）；**报价税率由用户填、不固定**。
- 各率（合格率/直营毛利/经销商毛利/报价税率）为空 → 跳过该步。
- 辅材是含税值，故 ÷1.13 折未税。管理费=0（人工已含，前端已移除显示）。
